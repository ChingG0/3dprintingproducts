# 產品路線圖

> 狀態：2026-09 討論中。設備：FDM 印表機（型號待補）。電子工具：尚無。
> 方向：A 線接現有通路（餐飲 POS / 水果電商）+ B 線獨立消費品。節奏：先走完一輪 T0。

## 各產品技術要點

### 4. 店家 NFC 展示立牌 — T0 主線

NFC tag 是被動元件，不需供電，所以仍是 T0。

- **最有商業價值的應用是 Google 評論導流**，因為店家有明確 ROI。其次：LINE 加好友、點餐、Wi-Fi 密碼、社群追蹤。
- Tag 選 **NTAG213**（144 bytes 使用者記憶體，放一條 URL 綽綽有餘）。NTAG215/216 是多花錢。
- 設計要點：
  - 背面留 tag 凹槽（Ø25mm tag → 凹槽 Ø26 × 深 0.6mm）
  - **tag 上方覆蓋厚度 < 2mm**，感應距離最佳（手機讀取距離約 20–30mm）
  - PLA / PETG 不導電，對 13.56MHz 無影響；**但絕不可貼在金屬面上**（渦流會直接讓 tag 失效）
  - 必須同時提供 QR code 當 fallback（舊 iPhone、Android 未開 NFC）
  - **QR 要用貼紙或雙色列印，不要用幾何刻痕** —— 對比度不足會掃不到
- **雙色列印 QR 是強差異化點**（若印表機支援多色/AMS）。
- 出貨前必須**寫入並鎖定** tag（NFC Tools 等 App 可設寫入保護），否則客戶或路人可改寫。
- 成本估：tag NT$8–15 + 列印件 NT$8–12 → 總成本 NT$20–30，售價 NT$150–250。

### 3. 小型溫室模組箱 — 戰略主線

**這是清單裡唯一能走完 T0→T4 整條階梯的產品**，且與本業（農產）直接相關。

階梯路徑：
- T0：模組箱體、卡扣連接件、面板框
- T1：通風口、可調百葉、磁吸門
- T2：USB 植物燈
- T3：溫濕度監測 + 自動灑水 + 風扇（ESP32-C3）
- T4：連網記錄、生長曲線

- **最大的商業風險是材積與運費，不是技術。** 大體積列印件運費會吃掉毛利。
  → **模組化的真正商業意義就是平板包裝（flat pack）**：小件拼裝、扁平出貨。
  → 台灣超商取貨限制約為「長+寬+高 ≤ 105cm、最長邊 ≤ 45cm、≤ 5kg」（各家略異，須自行確認）。所有設計要先滿足這個約束。
- **透光面板不要印**，外購 PET 片 / 壓克力，列印件只做框與連接。
- 材料：**用 PETG，不要用 PLA**。PLA 在長期高濕環境會水解變脆（數月尺度），且耐 UV 差。若放窗邊或戶外需考慮 ASA。
- 單件列印時間必須 < 90 分鐘，靠拼裝成大體積。
- 市場：育苗、香草、辣椒、多肉、菇類、發芽、水耕。台灣多肉與辣椒玩家社群活躍。
- 重複購買性高（模組可擴充）→ 高 LTV。

### 5. 小燈 — T1（現成燈芯版）

不用焊接就能做：外購 USB LED 模組 / 鈕扣電池燈片 / 太陽能庭園燈機芯，列印件只做燈罩與結構。

- **螺旋花瓶模式（vase mode）**：單層壁螺旋列印，無填充無頂層，印超快、省料、天然擴散。0.4 噴頭可把擠出寬度放大到 0.8–1.2mm 兼顧強度與透光。
- 白色 PLA 薄壁約 1mm 透光效果最漂亮。
- **LED 與壁面要留 15–20mm 擴散距離**，太近會出現亮點（hot spot）。
- PLA 玻璃轉化溫度約 60°C，密閉燈體 + 高功率 LED 會軟化變形 → 低功率，或改 PETG（約 80°C）。
- 氛圍燈是紅海，差異化只能靠造型 / IP。可考慮做品牌周邊。
- 後續 T3：可充電 + 觸控調光 + RGB。

### 2. 收納類 — 需要先收斂

通用收納是紅海，必須鎖利基或做系統。

- **模組化系統**是 3D 列印最強的收納切入點（可無限延伸產品線、重複購買）。
  - 若考慮採用現成開源系統（如 Gridfinity），**商用前必須先確認其授權條款**，我不確定條款內容，需查證。
  - 或自建規格，避開授權問題但要自己養生態。
- 利基方向：樂高 / 模型 / 釣具 / 美甲 / 咖啡器具 / 手工具 —— 小眾願付溢價。
- **同樣受材積運費限制**（重量體積比高），設計時要一併考慮包裝。
- 優點：無活動件、失敗率低、時間可控 → 適合 T0。

### 1. 矽膠翻模食品模具 — M 線，保留

流程：列印母模 → 翻食品級矽膠模 → 翻製食品（巧克力、冰、果凍、慕斯）；非食品向還有手工皂、蠟燭。
列印件只當母模、不接觸食品，所以規避了 FDM 的衛生問題。

必須注意的技術關卡：
- **矽膠必須用食品級鉑金矽膠（加成型 / platinum cure），不可用錫化矽膠（縮合型 / tin cure）** —— 錫催化劑有毒。
- **鉑金矽膠有「抑制固化」問題（cure inhibition）**：硫、胺、錫化合物、乳膠、某些光固化樹脂表面，會讓矽膠固化不全、表面發黏。PLA 一般沒問題，但**務必先小面積試打一塊再翻整模**。
- **FDM 層紋會 100% 複製到矽膠上** → 母模需打磨 + 補土 + 封層，或改用 SLA 列印母模（但 SLA 樹脂要完全後固化，否則抑制固化）。
- 翻模自身的技術：脫模斜度、澆口、排氣、氣泡（需真空脫泡或壓力鍋）、分模線。
- 成本問題：食品級鉑金矽膠約 NT$1,000–1,800/kg，一個模具用 200–500g → **材料成本 NT$200–750**，毛利被壓縮，且淘寶標準模具極便宜。
- 法規：若販售模具本身（模具屬食品器具），需保留原料的 FDA / LFGB 食品接觸證明。
- **結論：不適合當第一個產品。** 若要做，切入點是「客製化」（客戶 logo / 專屬造型），這是淘寶因起訂量而打不贏的區間。
